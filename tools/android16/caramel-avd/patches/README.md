# Caramel AVD source patches

These patches are applied by `prepare-caramel-car-avd.sh` to the checked-out
Android 16 AOSP source before building the Caramel arm64 Automotive AVD.

The patched Android source is AOSP code under the Apache License 2.0. The
patches and this documentation are Copyright 2026 Radio Sound, Inc. and are
also released under the Apache License 2.0. No binary or third-party runtime
dependency is introduced here.
